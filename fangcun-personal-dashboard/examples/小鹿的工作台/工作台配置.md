## 一、用户画像

- **身份 / 主要在忙什么**：做自媒体（小红书 + 短视频），同时在减脂
- **核心诉求**：选题老是想到就忘；减肥数据记不下来；每天该干什么没个准
- **隐私敏感度**：一般 —— 有体重和记账，不想被别人看到，但没有日记类内容
- **技术水平**：完全不懂代码

## 二、功能清单

| # | 功能 | 标识 | 类型 | 侧边栏 | 说明 |
|---|---|---|---|---|---|
| 1 | 今日计划 | `plan` | 本地 | 📅 今日计划 | 固定行程模板 + 按天勾选 + 临时待办 |
| 2 | 选题池 | `idea` | 本地 | 💡 选题池 | 点标题循环切换 待写→在写→已发 |

| - | 设置 | `settings` | 本地 | ⚙️ 设置 | 备份 / 清空 / 关于 |

## 四、数据结构

存储命名空间：`bysdash:`（敏感数据 `bysdash$secret:`，不进备份）

| Store key | 结构 | 归属功能 |
|---|---|---|
| `plan_template` | `[{id, time, text}]` | 今日计划（长期模板） |
| `plan_done:YYYY-MM-DD` | `[id]` | 今日计划（按天，自动重置） |
| `todo:YYYY-MM-DD` | `[{id, text, done}]` | 今日计划（临时待办，按天） |
| `idea` | `[{id, text, status, date}]` | 选题池，status ∈ new/doing/done |
| `weight` | `[{date, value}]` | 体重，按日期升序，每天最多一条 |
| `water:YYYY-MM-DD` | `number` | 喝水杯数 |
| `money` | `[{id, date, amount, type, category}]` | 记账，type ∈ in/out |
| `_lastBackup` / `_lastWrite` / `_lastPage` | timestamp / timestamp / string | 系统 |
