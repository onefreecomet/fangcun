# 更新日志

## v1.0.0 · 2026-07-31

首个发布版本。

**核心能力**
- 10 步引导流程，4 道显性检查点（功能清单 / 风格定版 / 确认单 / 本地验收）
- 8 套预置风格包 + 真实 HTML 预览（不用生图模型画假效果图）
- 三文件极小工程（index.html + manifest.json + icon.png），支持 PWA 加桌面
- 数据只存 localStorage，公网部署的只是空壳；内置备份提醒
- 迭代入口：产出《工作台配置.md》，第二次改动不用重新访谈

**工程质量**
- 静态检查脚本：占位符残留、分区标记闭合、iOS 字号、API key 泄漏、CDN 引用
- 冒烟测试脚本：无头 DOM 真跑一遍，抓 route 悬空、XSS 转义缺失、备份带出 key
- 失败分支覆盖访谈卡壳、脚本跑不动、部署卡住三段，五处重试上限
- 跨平台处理：`<py>` 探测、路径加引号、PowerShell 不用 `&&`
